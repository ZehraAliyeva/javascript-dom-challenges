Tez-tez verilən suallar

DOM (Document Object Model) HTML sənədinin brauzer tərəfindən obyektlər ağaci şəklində təqdim olunmasidir. JavaScript bu ağac vasitəsilə HTML elementlərini seçir, dəyişdirir, yaradir və silir.

getElementById() elementi yaliz id atributuna görə seçir. querySelector() isə istənilən CSS selektoru ilə işləyir və uyğun gələn ilk elementi qaytarir.

HTMLCollection live-dir, yəni DOM dəyişəndə avtomatik yenilənir. querySelectorAll() ilə gələn NodeList isə static-dir və sonradan dəyişmir. NodeList üzərində birbaşa forEach() işlədə bilərik.

remove() birbaşa elementin özü üzərində çağirilir və onu silir. removeChild() isə parent elementin üzərində çagirilir və göstərilən child elementi silir.

Eyni elementə eyni hadisə üçün bir neçə handler əlavə etməyə imkan verir. onclick property-si isə yeni funksiya təyin ediləndə əvvəlkini əvəz edir. Real layihələrdə əsasən addEventListener() işlədilir.
